Python Automation Toolkit

PYTHON
A set of automation tools for common file and data tasks: bulk renaming, CSV cleaning, and automated report generation.

File Renamer

Bulk-renames files in a folder to a consistent scheme.

CSV Cleaner

Drops rows with missing values and writes a clean dataset.

Report Generator

Produces summary statistics from the cleaned data.
